OHush — Vector Brand Kit
========================
All SVG files contain real editable paths, NOT embedded bitmap images. The serif lettering
has been converted to outlines, so no fonts must be installed. All backgrounds are
transparent. The approved white-space / gradient brand direction is preserved as a
vector reconstruction from the final approved raster artwork (minor tracing differences
are possible; it is not an original master vector supplied by the designer).

Color: Original purple gradients recreated as SVG gradients.
Solid: One-color dark purple (#3B1655 / #3A1653) for engraving, print and small sizes.
White: One-color reversed white for dark purple backgrounds.

Layout:
Horizontal = primary logo with icon + wordmark.
Stacked = alternate square-oriented logo.
Icon = character mark only for favicon, device, app and social avatar.
Wordmark = lettering alone, converted to individual vector shapes.

PDF versions are scalable vector output. EPS is exported for solid single-color
artwork when legacy print vendors request EPS.

You can open and edit SVGs in Figma, Adobe Illustrator, or Inkscape.
For very small physical printing, use the solid version; fine details of the face
need visual proofing at the chosen actual manufacturing size.
