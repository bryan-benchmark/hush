# The only score

A run that mutes the game is broken. Early, in the middle, or still muted after the game comes back: broken. A broken run has no accuracy. The seconds of game that were cut are the incident report. They are not a term in the percentage.

Accuracy is the lag at the change, scored on the commercial only.

**Start.** Seconds from the commercial's first sample until the mute. A commercial we never mute scores its whole length. A mute that begins while the game is still on marks the run broken and does not count as an early catch.

**Return.** Seconds from the game's first sample back until the unmute. An unmute while the commercial is still going scores the commercial seconds that play after the unmute. A mute that is still on when the game is back marks the run broken.

The percentage, and only on a run that is not broken, is commercial seconds actually held divided by 17,648.4. The 67,428 seconds of game are the thing we must leave playing. They are not points.

Play holds 0 of those commercial seconds. That is 0%. The old 79.26% counted the game.
